Ember Court is a turn-based card duel: you are the Ember Warden, and Warden Vex of the Hollow Court wants your thirty life. Four elements — Ember, Tide, Thorn and Stone — each told apart by colour and shape. Mana grows every turn, creatures strike at the start of your turn, Guards soak the blows, and playing two cards of one element in a turn Surges the second one (+2). Read Vex's intent banner, counter his plan, and reduce him to 0 life first.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network: the game is plain static files under `game/`.

Keyboard: 1–7 selects a card, Enter ends the turn, Esc cancels a selection.
